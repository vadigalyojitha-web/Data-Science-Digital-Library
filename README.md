# Data Science Digital Library

A student-focused library for Data Science course modules, learning tools, resources, assignments, lab experiments, and student profiles.

## Run locally

Serve this folder over HTTP so PDF.js can load the local PDF files. From this directory, run:

```powershell
python -m http.server 8000
```

Then open <http://127.0.0.1:8000/>.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The site will be served from the repository root.

The student profile details, photos, and student ID card image in this repository are intentionally published in the public site at the owner's request. This includes the student ID, email, faculty name, and profile links. Anyone can view or download these files, and Git history may retain them even if they are removed in a later update. Profile edits made in the browser are stored only in that browser's local storage and do not update the repository automatically.
